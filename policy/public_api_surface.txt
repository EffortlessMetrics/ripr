# Recorded public API surface of the `ripr` crate.
#
# This is a RECORDING of the surface that already exists, not an endorsement
# of it. Widening the gate to the transitive surface (#3052) made ~200 items
# visible that the previous lib.rs-only collector never saw; nothing here was
# newly exposed by that change. Narrowing any of it is separate work.
#
# A `#[macro_export]` macro appears as `pub macro ripr::<name>` even when its
# declaring module is private: Rust exports it at the crate root regardless of
# that module's visibility, so it is part of this surface.
#
# One line per module-level item reachable from `crates/ripr/src/lib.rs`
# through `pub mod`, in the form `<kind> <path>`. The collector lives in
# `xtask/src/public_api_surface.rs`.
#
# Not covered by this recording: public struct fields, enum variants, trait
# items, and associated functions in `impl` blocks. A `pub use` is recorded as
# the name it binds, not as the item it resolves to.
#
# Adding a line means accepting a public compatibility expectation. Removing
# an item without removing its line fails the gate in the other direction.
