# Contribution review evaluation

Maintenance-only scoring material. Do not supply this file, expected decisions, prior outputs or version labels to task workers. Use [the worker-only packets](pr-contribution-packets.json). Freeze criteria before viewing outputs. Score semantic judgment and preservation of the evidence, not headings, exact phrases, comment count or brevity.

For an executed comparison, use fresh isolated workers, the same prompt/case order/model/settings and one exact skill version each. Retain raw outputs and provenance; use held-out cases before claiming general improvement. If no isolated runner is available, record an owning-context walkthrough instead. Neither structural checks nor a walkthrough establishes independent model behavior, implicit skill selection or installation.
